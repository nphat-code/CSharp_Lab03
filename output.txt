7Swagger UI – Tài liệu và thử API trên trình duyệt
Swagger UI là giao diện web đọc file mô tả OpenAPI (JSON) và hiển thị danh sách endpoint,
kiểu dữ liệu request/response. Bạn có thể gửi thử GET/POST trực tiếp mà không cần Postman
haycurl .
7.1. Điều kiện
Đã cài Swashbuckle.AspNetCore , trong Program.cs cóAddEndpointsApiExplorer ,
AddSwaggerGen , và trong môi trường Development cóUseSwagger +UseSwaggerUI
như phần trên.
UseSwagger /UseSwaggerUI được đặt trong if (app.Environment.IsDevelopment())
đểkhông lộ tài liệu API chi tiết trên môi trường production. Khi deploy thật cần cấu hình
bảo mật riêng nếu vẫn muốn mở Swagger.
7.2. Bước 1 – Mở Swagger UI
Giữdotnet run đang chạy. Trên terminal, ASP.NET Core in địa chỉ lắng nghe (ví dụ http://localhost:5000
vàhttps://localhost:5001 ).
Mở trình duyệt, truy cập (thay cổng cho đúng với máy bạn):
Listing 6: URL Swagger UI (thường dùng HTTPS)
https://localhost:5001/swagger
Hoặc nếu chỉ dùng HTTP:
http://localhost:5000/swagger
Trang hiển thị tiêu đề kiểu Swagger UI , danh sách nhóm API (theo controller) và từng thao
tác.
7.3. Bước 2 – Thử GET /users
1.Mở rộng nhóm Users (hoặc tên controller của bạn).
2.Chọn GET /users →Try it out →Execute .
3.Xem Response body – JSON danh sách user; Response code phải là 200.
7.4. Bước 3 – Thử POST /users
1.Chọn POST /users →Try it out .
2.Trong ô Request body , nhập JSON, ví dụ:
{
"name ":"Pham Thi Dao"
}
3.Execute – kiểm tra 201 Created và body trả về có id,name .
